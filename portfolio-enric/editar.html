Cómo añadir imágenes y vídeos

Coloca tus imágenes o vídeos dentro de assets/media/ y escribe una ruta, por ejemplo assets/media/mi-juego.webp. Se recomienda usar imágenes WEBP/JPG optimizadas.

Para vídeo de YouTube o Vimeo pega la URL normal del vídeo. Para Sketchfab pega la URL del modelo. Para vídeos propios usa un archivo MP4. Para un modelo 3D en formato GLB usa el tipo «Modelo GLB».

Importante: editar aquí no actualiza los archivos automáticamente. Descarga contenido.js y reemplaza el original.
